The Agentic Layer — Three Agents Do the Work

Ingestion Agent

Watches every source — polls APIs where they exist, picks up file extracts where they don't — normalizes subject, site, visit and lab events into one canonical schema.

Identity Resolution Agent

Every incoming subject record is matched against the master index — same person, different platform ID → linked to a single SUBJ record across studies.

Insight Agent

Answers program questions in natural language against the linked model — no manual pulls, no pivot tables. Try it:
