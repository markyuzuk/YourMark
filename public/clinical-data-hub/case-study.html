Case Study

Clinical Data Hub for a Phase 3 Program

Endometriosis · Six active studies · One connected data layer

Client Situation

The Program

  • Clinical operations team at a biopharma company in Phase 3
  • Six active studies in endometriosis, from pivotal trials to a long-term extension
  • Some subjects move from one study into another

The Data

  • Subject, site, visit and lab data each sit on a different platform
  • Some platforms have an API; others only send file extracts
  • Data is split across studies and within each study

What the Team Needs

  • One connected data layer across all six studies
  • An executive view of enrollment and drop-off across the program
  • Answers in minutes, without manual data pulls
Problems to Solve
01

Unified Data Foundation

Pain Point

Subject, site, visit and lab data sit on separate platforms, within and across six studies. Some have an API and some don't — and subjects who move between studies are hard to follow.

Solve For
  • Ingest every source, through API or file
  • One linked data model across all six studies
  • Each subject matched across studies
02

Executive Program View

Pain Point

Each study reports on its own, so leaders have no single view of how the program is enrolling or where subjects are dropping off.

Solve For
  • Enrollment rate by study, site and month
  • Drop-off rate by study and over time
  • Total subjects in study, across the program

The YourMark Approach — Three Agents Do the Work

Ingestion Agent

Polls APIs and picks up file extracts; normalizes every source into one canonical schema.

Identity Resolution Agent

Links the same subject across platforms and studies into a single master record.

Insight Agent

Answers program questions in plain language against the linked model — no manual pulls.
